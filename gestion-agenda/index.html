PEAKPET · USO PROFESIONAL

Gestiona e invita a tus pacientes.

Dos alternativas para contactar a un tutor. Esta página no administra reservas ni almacena datos: las citas con fecha propuesta se gestionan dentro de tu cuenta personal de TidyCal.

Acceso profesional: para enviar una invitación con fecha y hora propuestas, inicia sesión en TidyCal. No compartas tus credenciales con clientes y no publiques claves ni tokens en esta web.

1. Proponer una sesión con día y hora

Utiliza el envío de invitaciones de TidyCal; el horario se bloquea provisionalmente hasta su confirmación.

  1. Inicia sesión en TidyCal.
  2. Abre Bookings → Create a booking.
  3. Selecciona «Evaluación Nutricional PEAKPET» y propone una fecha y hora.
  4. Introduce correo y nombre del tutor, y pulsa Send booking invite.
Abrir TidyCal ↗

El cliente confirma la invitación. Mientras está pendiente, el cupo queda retenido.

2. Enviar un enlace personalizado

Para que el tutor elija su horario, puedes preparar un mensaje desde Mail con sus datos precargados.

Se abrirá tu aplicación de correo para que revises y envíes el mensaje. Verifica que el remitente seleccionado sea fperez@alanapet.cl; no se envía automáticamente.

Abrir reserva pública ↗

3. Invitar desde Calendario de Mac

Crea un nuevo evento en el calendario de iCloud PEAKPET, define fecha, hora y duración. En «Añadir invitados» escribe el correo del tutor, confirma el invitado y guarda el evento para enviar la invitación. Ese evento se sincronizará con tu calendario de Mac.

Importante: la aplicación Calendario gestiona las invitaciones de este método. Evita registrar la misma sesión otra vez en TidyCal para no duplicar los eventos.
